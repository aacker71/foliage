# Foliage — historical capability ledger

> This is a dated audit from the August development loop. Its rows and counts are not the
> current integrated release verdict. Use [MILESTONES.md](MILESTONES.md) for the current
> release path and [progress-tracker.md](../context/progress-tracker.md) for later receipts.
> The `check:ledger` command can audit this record but does not certify a launch.


> **Historical snapshot:** at the August audit, no non-owner had used a surface of this product.
> Per `CLAUDE.md` §1, `SELECT` is therefore restricted to rows that change what a non-owner sees,
> until this line names a person, a date, a surface, and what broke. It is stale at 14 days.
> *This is the honest empty state. Do not fill it with a hypothetical user.*

**Within this historical ledger, each capability has one row.** The retired loop selected
one incomplete row at a time. Its statuses are preserved as audit history; the current
release path and later verification receipts are linked above.

**`SELECT` order, highest first** (`CLAUDE.md` §1, mechanic 4): a launch surface with **zero rows**
→ a **proven defect** → a **user-facing** row → a **mechanism**. Picking a mechanism requires
naming the user-visible failure it prevents and the date that failure last occurred.

Status vocabulary, and it is deliberately narrow:

| Status | Means |
|---|---|
| `DONE` | a user can use it in the real running app, verified end to end with browser evidence |
| `BUILT` | the code exists and its own tests pass, but nothing has exercised it as a user would |
| `PARTIAL` | some of it works; the row says which part does not |
| `DARK` | shipped but unreachable — a route with no caller, a package with no consumer |
| `BROKEN` | it existed and regressed |
| `TODO` | not started |
| `GATED` | blocked on an owner decision, named in the row |

`BUILT` is not `DONE`. That distinction is the whole point of the column — today a design run
reported "bounding boxes computed, margins balanced" while the rendered SVG had content 14.4
units outside its viewBox, and separately a contrast table passed because the wrong WCAG
threshold was applied to an 11px label. Both were correct arithmetic against the wrong
reference. Only looking at the running thing catches that.

Priority order for selection: `BROKEN` > `DARK` > `PARTIAL` > `TODO` > `BUILT` (re-verify).
