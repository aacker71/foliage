# /autoplan audit — 2026-08-20

Four independent reviewers (CEO, Eng, Design, DX) plus a Codex CEO voice, run against the tree at
806 tests green. Nothing here is invented: every finding below was reproduced or measured by the
reviewer that reported it. Findings are recorded with their severity as given.

## THE CROSS-PHASE FINDING — three reviewers, three lenses, one root cause

The CEO, DX and Design reviewers each arrived, independently and by different routes, at the same
defect. That convergence is the strongest signal this pipeline produces.

**`README.md` states the rule:** the sentence *"0 verified is the correct result for unsigned
history"* is permitted ONLY when nothing went unchecked — *"otherwise that sentence would be a
confident claim about commits nobody read."*

**The CLI obeys it. The page prints it anyway.** Measured: intake reports `1 commit(s) CARRY A
SIGNATURE THIS MACHINE DID NOT CHECK` and correctly withholds the sentence; `render.ts:828` gates
the plate on `outward.length === 0` — verified-count alone — and prints it.

**Root cause is structural, not copy.** The leaf document is `{id, subject, leaflets}`; a leaflet
is `{id, title, tier, provenance, visibility}`. Every signature finding intake computes —
`unchecked`, `unbound`, `undeclared`, `rejected`, `unrecognized` — is written to stdout and
DISCARDED. Rendered pages containing the word "gpg": **zero**. The web surface is structurally
incapable of the honesty the CLI practises.

The Design reviewer put the consequence best: the product *already computes the sentence that
would make "0 verified" feel like integrity, and throws it away.*

## THE NUMBER THAT REFRAMES THE PRODUCT

**0 of 681 leaflets verified on the owner's own portfolio. "Selected work" — the hero — is empty.**
55% of the page is rejection notices, 45% unclaimed. `verified` needs a signature git accepted AND
a signer bound to a declared identity; on most machines gpg is absent so none can be checked, and
GitHub's web-flow signature binds to GitHub's key, not the subject — classifying as `undeclared`.

CEO verdict: *"The flagship section of the flagship page is empty for essentially every real user,
on day one. Intellectually right, commercially fatal."*

## CRITICAL — acted on immediately

- **A server was serving fabricated humans.** Port 4291 served "Northwind Instruments" with four
  invented people carrying `verified` tiers on this repo's real commits. A legitimate /tmp test
  corpus — and the ONLY context in which this product's flagship tier has ever rendered. Killed.
  Fix owed: a synthetic-subject surface must never bind a port outside a test, and the `example`
  flag already exists to mark it.
- **The README asserted a falsehood.** "CI has never run: there is no remote" — `gh run list -R
  aacker71/foliage` shows real runs including a failure on 2026-08-18. Corrected, with the reason
  it survived four days of self-auditing recorded beside it.

## HIGH — open

- **The publish policy is on the wrong surface.** The leaf answers 404 for a denied leaflet; the
  canopy answers 200. The safety rail was built where there is no audience and is absent where
  there is one. (CEO §6)
- **Verbatim commit titles reach a public `<h1>`** and can carry third parties' email addresses.
  Named as a de-facto FCRA gate in LAUNCH.md Gate 0; marked, not fixed, across C1/C2/C3/C5.
- **`perf: cut p99 by 40%` is denied by `deny-rating-shaped-title`.** "No rating of a person" and
  "no number in a title" are different rules and have been conflated. The user's most impressive
  true engineering result is unpublishable. (CEO 2f)
- **No eval harness.** 806 tests and not one can tell you whether a human would hire this person.
  "Every claim cites evidence" is traceability, not accuracy.
- **`TESTER-QUICKSTART.md` is excellent and the README links it zero times.** It already solves
  TTHW, identity discovery and the 0-verified cliff. One line recovers it. (DX §4)
- **README order is reverse-dependency**: install → server → … → intake. Following it literally
  forces a backtrack of 100 lines to find the command that produces what the server renders.
- **`EADDRINUSE` prints a raw 12-line Node stack** — the single most likely first-run error, and
  the README already documents the fix it fails to print. (DX §2)
- **Every CLI example in the README is a shell syntax error** — `<id>`, `<path>` are redirect
  operators. All four fail on copy-paste. (DX §4)
- **The accent is absent, not overused.** Measured chartreuse on rendered pages: `/tree` 0,
  `/leaf/<id>` 0, `/leaflet/<id>` 0, `/review` 0. It is 1.68:1 on paper so it cannot be text on
  any day surface, and every public surface is day. The biophilic system renders beige-on-beige.
  Its one correct use is in a mockup nobody ships. (Design F11)
- **Loader diagnostics occupy the `/tree` hero** — two 40px numerals reading `LEAVES LOADED 1`
  and `NAMED BY MANIFEST 1`, while the one human on the page is a small link 600px below.
- **Server filesystem paths render on public pages** (`/tmp/tree/alex.leaf.json`) on the plane
  labelled "ANYONE MAY READ THIS".
- **`.loop/state.json` is stale by 5 days** and says "C2 is DONE" while the ledger says PARTIAL —
  the exact cursor-drift bug its own comment claims was fixed.
- **Four rows describe uncommitted code** (C2, C7, C8, X7). `policy.mjs` and `share.mjs` are
  untracked: a fresh clone of `main` gets 2 of 5 CLIs.

## THE STRUCTURAL FINDING

> The loop selects "highest-priority incomplete row", `BROKEN > DARK > PARTIAL > TODO > BUILT`.
> **S3 has no rows. So the mechanism the team trusts to allocate attention is structurally
> incapable of ever allocating attention to the largest unbuilt thing in the company.**

Measured: `grep -rn 'tenant|billing|stripe|subscription|signup|oauth|password'` over every `.ts`
and `.mjs` returns **132 hits, every one a test fixture or prose. Not one line of platform code.**

Fix: write the S3 rows even as TODO — *existing means selectable; not existing means invisible* —
and add a Select rule that a launch surface with zero rows outranks any PARTIAL row.

## COMPETITIVE — the two closest analogues are dead

Polywork closed Jan 2025 having raised $40M+. Read.cv was acquihired by Perplexity and wound down
May 2025 — the best-designed artifact in the category; design did not save it. Both died on
distribution, which is the axis this product has not addressed. The real competitor is whoever
ships verification *inside the ATS*.

The one moat nobody has priced: the **FCRA posture**. This is built to be legally safe to show an
employer, and ranking-based incumbents arguably are not. That is an enterprise/gatekeeper moat,
not a consumer one, and it is not the current pitch.
