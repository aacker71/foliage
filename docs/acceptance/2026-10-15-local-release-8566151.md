## Size and hosting

The file is 86.9 MiB, under GitHub's 100 MiB limit for a file and over its
50 MiB warning, so pushing it draws a warning, which is expected. Served from
this site, each download draws about 90 MB of the Vercel Hobby plan's 100 GB of
monthly transfer: roughly 1,100 downloads a month before Vercel pauses the
team. That is arithmetic on the 100 GB allowance given in the release brief,
not a measured bill, and the allowance was not checked against Vercel's current
terms here.
