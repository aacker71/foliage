# Documentation index

**Current:** [STATE.md](STATE.md) says what works, what is in flight and what is not verified.
[../DEVELOPMENT.md](../DEVELOPMENT.md) covers setup and the gate. [../AGENTS.md](../AGENTS.md) holds the
rules that are easy to get wrong. [../TESTER-QUICKSTART.md](../TESTER-QUICKSTART.md) is the user journey.

**Design and contracts:** product, architecture, UI and integration documents such as
`SYSTEM-ARCHITECTURE.md`, `CONTRACTS.md`, `UI-FOUNDATION.md` and `INTEGRATIONS.md`. They describe
intended behaviour and constraints. Where one disagrees with the code, the code and its tests win.

**Historical:** anything dated in its filename (`AUDIT-2026-08-24.md`, `SCARLET-EXECUTION-2026-09-11.md`),
`acceptance/`, `execution/`, `archive/`, and the top-level `.loop/` and `context/progress-tracker.md`.
These are dated records of how the project got here. Their branch names, pull request numbers and test
counts were true on their date and are not current evidence. Links to `aacker71/foliage` pull requests
point at the original private repository's history, which is not part of this tree.
